roadnet_min — synthetic ped-equipped SUMO net (road-net-import regression fixture)

Purpose:
  An INPUT net.xml only — NOT a parity golden. There is no golden.fcd.xml / golden.state.xml
  and no trajectory comparison against SUMO. The offline test loop loads this net into
  LiveCitySim (SumoSharp's own engine + the SumoRouteGraphNav route-graph provider) and asserts
  that pedestrians route on the ped graph and cross at crossings, with no walkable-polygon bake.
  Because nothing here is compared to a SUMO-produced trajectory, the SUMO version used to
  GENERATE the net does not affect parity (unlike the demo_city goldens, which require the
  SUMO_VERSION-pinned build).

Generated by:
  netgenerate --grid --grid.number=3 --grid.length=120 \
              --sidewalks.guess --crossings.guess --walkingareas \
              --default.lanenumber 1 --no-turnarounds \
              -o net.xml

Tooling:
  Eclipse SUMO netgenerate Version 1.20.0 (pip `eclipse-sumo==1.20.0`, matching the SumoSharp
  SUMO_VERSION pin exactly -- not required for this fixture since it isn't a parity golden (see
  "Purpose" above), but used anyway: the Ubuntu apt package (1.18.0) does NOT emit the
  `outlineShape` attribute on crossing lanes, which `PedNetworkParser` reads into
  `PedCrossing.Outline` and `WalkablePolygonBaker.Bake`/`BakeCrossingsOnly` require (>=3 vertices)
  to bake a Crossing polygon at all -- without it `CrossingOccupancySource` never sees any
  crossing geometry and no ped can ever register as "on a crossing", regardless of routing. 1.20.0
  populates it. REGENERATED 2026-07-25 for exactly this reason (Stage C's road-net smoke test
  needs PeakOccupiedCrossings>0 to prove routing actually threads a crossing). Structurally
  identical to the original 1.18.0-generated fixture otherwise (same edge/lane/crossing/
  walkingarea counts and ids; walkingarea corner-smoothing coordinates differ by <0.2 in the
  least significant digit from the version bump, cosmetic).

Contents (a 3x3 grid, ~240m x 240m, projParameter="!"):
  - 24 non-internal vehicle edges (one lane each)
  - 148 pedestrian lanes (sidewalks)
  - 20 crossings (function="crossing"), each WITH an outlineShape (a real Crossing polygon bakes)
  - 24 walkingareas (function="walkingarea")
  - full pedestrian <connection> stitching (sidewalk <-> walkingarea <-> crossing)

No proprietary data. Regenerate with the command above (using SUMO 1.20.0, not the apt 1.18.0
package -- see "Tooling" above) if the fixture ever needs refreshing; update this file's
date/version if so.
