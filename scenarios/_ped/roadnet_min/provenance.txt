roadnet_min — synthetic ped-equipped SUMO net (road-net-import regression fixture)

Purpose:
  An INPUT net.xml only — NOT a parity golden. There is no golden.fcd.xml / golden.state.xml
  and no trajectory comparison against SUMO. The offline test loop loads this net into
  LiveCitySim (SumoSharp's own engine + the SumoRouteGraphNav route-graph provider) and asserts
  that pedestrians route on the ped graph and cross at crossings, with no walkable-polygon bake.
  Because nothing here is compared to a SUMO-produced trajectory, the SUMO version used to
  GENERATE the net does not affect parity (unlike the demo_city goldens, which require the
  SUMO_VERSION-pinned build).

Generated by:
  netgenerate --grid --grid.number=3 --grid.length=120 \
              --sidewalks.guess --crossings.guess --walkingareas \
              --default.lanenumber 1 --no-turnarounds \
              -o net.xml

Tooling:
  Eclipse SUMO netgenerate Version 1.18.0 (Ubuntu apt package; the SumoSharp golden pin is
  SUMO_VERSION 1.20.0, which is NOT required here — see "Purpose" above).

Contents (a 3x3 grid, ~240m x 240m, projParameter="!"):
  - 24 non-internal vehicle edges (one lane each)
  - 148 pedestrian lanes (sidewalks)
  - 20 crossings (function="crossing")
  - 24 walkingareas (function="walkingarea")
  - full pedestrian <connection> stitching (sidewalk <-> walkingarea <-> crossing)

No proprietary data. Regenerate with the command above if the fixture ever needs refreshing;
update this file's date/version if so.
